## Real-time Location Tracking Dashboard

This dashboard listens to Firebase Realtime Database at:

- Database: `https://bsf-realtimedata-default-rtdb.firebaseio.com/`
- Node: `Tracking`
- Supports the legacy shape with timestamp child keys like
  `2026-04-20_01-57-21`, where each child contains `Latitude`, `Longitude`,
  and `Accuracy`.
- Also supports a direct record with `Timestamp`, `Latitude`, `Longitude`,
  `Accuracy`, and additional fields such as `SoldierID`, `Status`, `Link`,
  `LocationMode`, `Simulated`, and `RSSI`.

### Run locally

From the repo root:

1. `cd bsf-dashboard`
2. `npm install`
3. `npm start`

### Notes

- If you don’t see data, verify your Realtime Database rules allow reads for your app/user.
- Invalid points are filtered out by default when `Accuracy > 1000`.
